# Social listening & direct engagement

The channel that's already running. A Claude job continuously scans public discussions for
people hitting the exact pain SnippAI solves, and surfaces threads worth a genuine reply.

## The job

**Platforms scanned:** X/Twitter, Reddit, Hacker News, and dev forums.

**What it looks for** — conversations about:
- Sending / pasting **screenshots or images into Claude Code** (or into a terminal AI agent).
- The **alt-tab / copy-paste friction** of showing an AI tool something visual while coding.
- People asking *"how do you get a screenshot into Claude Code?"* or complaining about the flow.
- Broader terminal + screenshot + AI-pair-programming workflow chatter where SnippAI fits.

**Output:** a surfaced thread with enough context to judge fit and craft a specific reply.

## How a surfaced thread becomes an engagement

1. **Judge fit.** Is this person actually in the ICP (Mac + Claude Code + terminal)? If they're
   on Windows/Linux or not using Claude Code, usually skip — SnippAI won't help them.
2. **Read the whole thread** before replying. Answer the actual question first.
3. **Reply genuinely.** Lead with something useful; mention SnippAI only if it truly fits.
4. **Disclose** you're the maker. Always.
5. **Link only when relevant** — and prefer the site (snippai.dev) or a demo clip over a raw
   download link.
6. **Log it** in the table below.

## Engagement rules (non-negotiable)

- **Helpful first, promotional second.** If the tool doesn't fit, don't shoehorn it in.
- **Disclose maker status every time.** "I built a small tool for this — SnippAI…"
- **Never paste identical replies.** Reuse the *shape* of a template, not the words. Duplicate
  copy reads as spam and gets flagged.
- **One reply per thread.** Don't pile on or argue.
- **Respect each community's rules.** Some subreddits forbid self-promo outright — participate
  there without linking, or not at all.
- **Terminal-first, honest about setup** (the global guardrails apply here too).

Reply skeletons live in [copy/x-reply-templates.md](copy/x-reply-templates.md).
