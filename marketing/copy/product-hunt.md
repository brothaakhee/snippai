## Description

```
SnippAI is a native macOS menu-bar app for developers using Claude Code.

Hit ⌥⇧4, drag a region of your screen, type a message in the panel that pops up, and
it fires the screenshot + your text straight into the Claude Code session you already
have running in your terminal. Claude's reply streams back in the same panel. No
saving files, no alt-tab, no leaving the screen you're debugging.

It's genuinely native — owns the capture pipeline (ScreenCaptureKit) and talks to
iTerm2 over its socket API, with a live mirror of your session so you always know
which one you're sending to. Terminal.app supported too.

$8.99 once. 7-day free trial. No subscription. macOS 14+.
```
