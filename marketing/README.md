## The one-paragraph thesis

The audience is **small and precisely locatable** — Mac devs using Claude Code in a terminal.
So we concentrate on being present where they already gather (r/ClaudeAI, Claude Code Discords,
X, Hacker News, awesome-lists) rather than buying broad reach. The product is **visual**, so we
lead with the demo clip everywhere. And at **$8.99 one-time** it's an impulse buy — the job is
discovery + a frictionless trial, not a nurture funnel.

## Two guardrails for all copy

1. **Lead with the terminal / iTerm2 story.** That's the genuinely native, best-in-class part.
   Claude Desktop is "works with" aspirationally — never headline it.
2. **Be honest about the one setup step** (enabling the iTerm2 Python API — a one-time toggle +
   Allow dialog). Frame it as "one 10-second setup," don't hide it.
