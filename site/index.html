// faq

Good to know

Does it work with my existing Claude Code session? +

Yes — that's the whole point. SnippAI is a second window onto the session you're already running, not a new process. Type in the panel or your terminal and they stay in sync.

How does it send into the Claude desktop app? +

It brings your conversation to the front, pastes your message + screenshot, and submits — then returns you to the app you were on. The desktop session runs on your Mac, so it reads the screenshot directly. Needs a one-time Accessibility grant.

Which terminals are supported? +

iTerm2 (full fidelity — live color mirror, cycling, status badges) and Terminal.app (basic — send, focus, and a polled plain-text mirror), plus the Claude desktop app. More may come later.

Does my data leave my machine? +

No. SnippAI talks to your local terminal and the desktop app directly — captures stay on disk, nothing is sent to a server. Your prompts go only into your own Claude session.

Is it a subscription? +

No. A 7-day free trial, then a single one-time purchase unlocks every feature forever, with free updates. No tiers, no recurring fee.

What do I need to set up? +

macOS 14 or later. On first run SnippAI asks for Screen Recording and Automation (and Accessibility for the desktop app); for iTerm2 you enable its Python API once. Then just press the hotkey.
